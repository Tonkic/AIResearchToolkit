# AIResearchToolkit

面向科研工作者的 AI 工具目录。

## Math

- [Rethlas](https://github.com/frenzymath/Rethlas) — 由生成与验证 Agent 协作完成数学证明推理与校验。

## Search

- [paper-search-cli](https://github.com/dr-dumpling/paper-search-cli) — 面向 Agent 的论文检索、引文扩展、期刊指标和 PDF 发现 CLI。
- [gs-skills](https://github.com/cookjohn/gs-skills) — 通过 Google Scholar 检索论文、追踪引用并导出到 Zotero。
- [AnySearch](https://www.anysearch.com/docs) — 为 AI Agent 提供实时网页搜索和全文内容抽取。
- [instsci](https://github.com/Rimagination/instsci) — 优先开放获取，并复用用户已有机构权限获取订阅论文。

## Data

- [MinerU](https://github.com/opendatalab/MinerU) — 将 PDF 和 Office 文档解析为适合 LLM 使用的 Markdown 或 JSON。
- [scansci-pdf](https://github.com/Rimagination/scansci-pdf) — 聚合多种来源和机构访问路径，支持论文 PDF 检索与批量处理。

## Code

- [Humanizer](https://github.com/Humanizr/Humanizer) — .NET 文本处理库，提供人性化字符串、日期、数字和复数格式化功能。
- [langchain](https://github.com/langchain-ai/langchain) — 构建 LLM 应用、工具调用和 Agent 工作流的开发框架。
- [mmdetection](https://github.com/open-mmlab/mmdetection) — 基于 PyTorch 的目标检测工具箱和研究基准。

## Write

- [research-writing-skill](https://github.com/Norman-bury/research-writing-skill) — 面向科研论文写作的 AI 辅助技能包。
- [nature-skills](https://github.com/Yuan1z0825/nature-skills) — 涵盖科研写作、统计审查和科研绘图的可复用技能库。

## Review

- [letpub-skills](https://github.com/Yon8/letpub-skills) — 查询期刊信息并根据论文摘要辅助选择投稿期刊。
- [paper-lifecycle](https://github.com/M1n-n9/paper-lifecycle) — 覆盖论文写作、审稿、返修和定稿的工作流工具。

## Figure

- [scipilot-figure-skill](https://github.com/Haojae/scipilot-figure-skill) — 辅助生成适合论文发表的科研图表。
- [paper-framework-figure-studio-pro](https://github.com/c-narcissus/paper-framework-figure-studio-pro) — 设计论文方法框架图和研究流程图。
- [paper-plot-skills](https://github.com/Trae1ounG/paper-plot-skills) — 复现和绘制符合论文规范的实验图表。
- [Auto-Visio-Helper](https://github.com/0Antique/Auto-Visio-Helper) — 根据自然语言生成可编辑的科研示意图。

## Slides

- [powerpoint-skill](https://github.com/Noi1r/powerpoint-skill) — 生成包含公式、图表和结构化内容的可编辑 PPT。
- [beamer-skill](https://github.com/Noi1r/beamer-skill) — 辅助创建和审校 LaTeX Beamer 学术演示文稿。
- [GordenSuperPPTSkills](https://github.com/GordenSun/GordenSuperPPTSkills) — 将图片格式的幻灯片逆向还原为可编辑 PPTX。
- [ppt-master](https://github.com/hugohe3/ppt-master) — 根据文档或主题生成包含图表的原生 PPT。

## Agent

- [academic-research-skills](https://github.com/Imbad0202/academic-research-skills) — 覆盖研究构思、检索、写作、评审到定稿的技能套件。
- [academic-research-skills-codex](https://github.com/Imbad0202/academic-research-skills-codex) — 面向 Codex 的原生学术研究技能套件。
- [AI-Scientist-v2](https://github.com/SakanaAI/AI-Scientist-v2) — 使用 Agent 自动生成、实验和评估科研想法。
- [AutoResearchClaw](https://github.com/aiming-lab/AutoResearchClaw) — 尝试自动完成从研究想法到论文生成的科研流程。
